# Инструкция по развёртыванию RampPulse на VPS (Ubuntu 22.04 / 24.04 LTS)

Данная инструкция позволяет поднять серверную часть RampPulse на вашем VPS сервере с Ubuntu и настроить передачу текстовых сообщений, онлайн-синхронизацию и голосовую связь (Walkie-Talkie).

---

## 1. Подготовка сервера

Подключитесь к вашему VPS по SSH:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

Убедитесь, что на сервере установлен `git`:
```bash
apt update && apt install -y git
```

---

## 2. Клонирование и установка

1. Склонируйте проект в любую удобную папку (например, `/root/ramppulse`):
```bash
git clone https://github.com/TEXNOLONG/project.git /root/ramppulse
cd /root/ramppulse
```

2. Запустите автоматический скрипт установки:
```bash
sudo bash deploy/install_ubuntu_vps.sh
```

### Что делает скрипт автоматически:
- Устанавливает Python 3, `venv`, `pip`, `nginx`, `ufw`.
- Создаёт системного пользователя `ramppulse` и каталоги `/opt/ramppulse/app` и `/var/lib/ramppulse` (для SQLite базы данных).
- Настраивает виртуальное окружение и устанавливает зависимости.
- Создаёт и активирует службу systemd `ramppulse.service` (автозапуск при перезагрузке сервера).
- Настраивает веб-сервер Nginx для проксирования REST API и WebSocket-соединений (`/ws` и `/ws/voice/` для голосового чата).
- Настраивает файрвол UFW (открывает порты 80, 443 и 22).

---

## 3. Проверка работы сервера

Проверьте статус службы бэкенда:
```bash
systemctl status ramppulse
```

Проверьте ответ сервера:
```bash
curl http://127.0.0.1:8000/healthz
```
Ответ должен быть: `{"ok": true, "airport": "..."}`.

В браузере или в приложении откройте:
```
http://IP_ВАШЕГО_СЕРВЕРА
```

Демо-учётные записи для входа:
- **Диспетчер:** `dispatcher@oto.ru` / `Dispatcher2026!`
- **Инженер:** `tech1@oto.ru` / `Engineer2026!`

---

## 4. Подключение бесплатного SSL-сертификата (HTTPS/WSS)

Если у вас есть доменное имя, направленное на IP вашего VPS (A-запись):

1. Откройте файл конфигурации Nginx:
```bash
nano /etc/nginx/sites-available/ramppulse
```
Замените строку `server_name _;` на ваше доменное имя, например:
```nginx
server_name dispatch.my-domain.ru;
```
Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`) и перезагрузите Nginx:
```bash
nginx -t && systemctl reload nginx
```

2. Получите бесплатный сертификат Let's Encrypt:
```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d dispatch.my-domain.ru
```
Certbot автоматически обновит конфигурацию Nginx и включит защищённое соединение HTTPS и WSS.

---

## 5. Как работает голосовой чат через VPS

- Голосовой чат работает по бинарному WebSocket-каналу на эндпоинте `/ws/voice/{call_id}`.
- Аудиопоток с микрофона (16 кГц, 16 бит моно) передаётся на сервер и мгновенно перенаправляется второму участнику вызова с минимальной задержкой (< 20 мс).
- Так как передача идёт через Nginx/WebSocket напрямую на VPS, она **не блокируется роутерами, NAT и мобильными операторами** (в отличие от обычного P2P WebRTC).
